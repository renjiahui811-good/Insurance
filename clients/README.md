# Clients

Client profiles for your AIA advisory work.

⚠️ **Privacy / PDPA:** Client files contain personal data. Do **not** commit real
client information to a shared or public repository. This folder is listed in
`.gitignore` (except the template and this README). Keep real client data local
or in a secured, private store.

- Copy `_template_client.md` to a new file, e.g. `client-0001.md`.
- Naming convention: `client-{code}.md` — prefer codes over full names.
- Record PDPA consent before storing any personal data.
